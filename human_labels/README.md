# Human checks

- `spotcheck_pcm.csv`, `spotcheck_ha.csv`: translation spot-checks from notebook 1. Each row is marked `y` if the translation keeps the meaning, `n` if not. The report quotes the share marked `y`.
- `natural_pcm.csv`, `natural_ha.csv` *(planned)*: about 50 real model answers per language, pre-labelled by the API judge, confirmed or corrected by the author.

The annotator is the author, who reads Nigerian Pidgin and Hausa fluently.
